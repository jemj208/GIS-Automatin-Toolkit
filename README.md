# GIS Automation Toolkit

A growing collection of Python and ArcPy tools for automating practical GIS workflows in ArcGIS Pro.

## Tools

| Tool | Description |
|---|---|
| [Raster Clip by Plan Boundaries](raster/clip_rasters_by_plan_boundaries.py) | Matches raster plans with polygon identifiers and clips them automatically. |
| [Group Layer to KMZ](kmz/export_group_layer_to_kmz.py) | Exports visible layers from an ArcGIS Pro Group Layer into a single KMZ file. |
| [Excel Schema Standardizer](tools/Excel-Schema-Standardizer) | Standardizes different Excel schemas into a consistent GIS dataset using configurable field and value mappings. |

## Technologies

Python · ArcPy · ArcGIS Pro · KML/KMZ · XML

## Usage

Each script contains configurable input paths, layer names, fields, and output locations.

No project-specific or proprietary data is included.
