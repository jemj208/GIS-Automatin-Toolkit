# GIS Automation Toolkit

A growing collection of Python and ArcPy tools for automating practical GIS workflows in ArcGIS Pro.

## Tools

| Tool | Description |
|---|---|
| [Raster Clip by Plan Boundaries](raster/clip_rasters_by_plan_boundaries.py) | Matches raster plans with polygon identifiers and clips them automatically. |
| [Group Layer to KMZ](conversion/group_to_kmz.py) | Exports visible layers from an ArcGIS Pro Group Layer into a single KMZ file. |
| [Excel Schema Standardizer](data-management/Excel-Schema-Standardizer) | Standardizes different Excel schemas into a consistent GIS dataset using configurable field and value mappings. |
|| [Project Geometry Metrics](data-management/project_geometry_metrics.py) | Matches project names from Excel with GIS features and extracts geometry metrics using ArcPy. |

## Technologies

Python · ArcPy · ArcGIS Pro · KML/KMZ · XML

## Usage

Each tool contains configurable inputs and can be adapted to different GIS projects and datasets.

No project-specific or proprietary data is included.
